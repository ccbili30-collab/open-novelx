## 当前范围

本批只实现 OpenCode 内核 NovelX 的“世界面”分阶段真实 Growth（生长）链路：总主编注册题材自适应的阶段骨架；每一阶段使用一个干净的阶段主编会话；阶段主编读取已经提交的权威上游原文，注册本阶段实体及多对多依赖，再把实体交给叶子 Agent（智能体）撰写；阶段审查封存后，总主编写入记忆检查点并进入下一阶段。

本批停止于世界法则、自然、人群、组织、经济与文化信仰。图片、地图、历史、故事、角色、图谱和世界包导出不在本批范围内。缺少真实 Provider（模型服务）、来源未读取、来源哈希漂移、Agent 身份不匹配或阶段未封存时均失败关闭，不使用本地模板冒充 Live（真实运行）。

## 已实现

- 物化合同升级为 `schemaVersion: 2`，记录阶段主编会话、精确来源读取、来源 SHA-256、多对多依赖、阶段交接、Context Epoch（上下文纪元）和记忆检查点。
- 派发权限固定为 `growth → novelx-stage-editor → novelx-world-writer`。总主编不能注册阶段实体或提交档案，阶段主编只能处理绑定阶段，叶子不能创造规则、派生 Agent 或修改正式文件。
- 每个阶段只创建一个干净的阶段主编会话；叶子获得的是本实体的注册要求和已验证上游原文，不继承总主编或上一阶段的工具调用历史。
- 阶段主编必须先通过受控工具读取真实上游实体，随后才能以实体 ID 注册来源关系；Harness（智能体运行框架）验证读取覆盖、来源哈希、阶段身份、路径所有权与提交状态。
- 最后一份档案提交后阶段进入审查态；显式封存会生成确定性交接记录。总主编只能在阶段封存后建立记忆检查点，并由权威蓝图、物化账本、交接记录和来源索引恢复上下文。
- 记忆检查点改为自动继续压缩；压缩后的根会话调用恢复工具重新取得权威进度，不依赖模型摘要作为事实底座。
- 桌面 UI（用户界面）显示总主编、阶段主编、叶子和实体层级；投影来源读取数、多对多关系、来源哈希、交接与上下文纪元。正在流式写作的文件保持只读，正式提交后展示排版正文。
- 宽屏保留会话、世界树、正文和详情四区；窄窗沿用覆盖式详情规则。未添加本轮冻结范围之外的图片、故事或角色假界面。
