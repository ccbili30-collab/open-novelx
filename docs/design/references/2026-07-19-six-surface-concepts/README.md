## 使用边界

- 六张唯一概念图的内容组织可以作为讨论输入，但它们的外壳、侧栏顺序、会话宽度、详情面板和图标并不一致。
- 实现前必须先确定统一的 App Shell（应用外壳）、六类信息架构、面板切换规则和窄窗口折叠顺序。
- 不得从概念图推断真实 Provider（模型服务）、Agent（智能体）、保存、发布、Canon（正典）或版本状态。
- 原始来源文件仍保留在 Codex 附件与生成图片目录；仓库副本用于版本化评审。
