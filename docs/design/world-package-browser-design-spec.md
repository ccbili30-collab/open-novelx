# NovelX 世界包浏览器视觉规格

状态：2026-07-23 已批准参考的实现规格

视觉基准：`C:\Users\16014\Desktop\NovelX-世界包浏览器预览.html`
目标截图视口：1600 × 1000

## 构图

- 整个视口是一片无边框的深色虚空，不出现网页长卷、信息看板、传统顶栏或侧栏。
- 左上角保留 `NOVELX · WORLD ARCHIVE` 品牌标记；右上角显示当前页与状态。
- 中央唯一主舞台使用 CSS 3D 透视。封面状态约宽 640px、高 760px；内容页约占视口宽 76%、高 72%。
- 页面顺序固定为：封面 → 世界地图 → 历史、文献与小说 → 人物群像 → 世界图谱。
- 右侧垂直圆点表示页面位置；底部中央显示滚轮/拖动提示；正式界面不保留原型的动效比较器。

## 色彩与材质

- 虚空底色：`#04070d`；中心雾光使用低透明度蓝灰径向渐变。
- 纸面文字：`#eee8d8`；金色细节：`#c4aa74`；内容表面使用 `rgba(9, 13, 21, 0.62)`。
- 内容容器只保留极细边线、轻微内发光和深阴影，不使用圆角卡片墙。
- 中文标题使用宋体类衬线字体；导航、状态和页签使用 Segoe UI 类无衬线字体。

## 星空

- 不使用重复径向渐变贴图。
- 以世界标题为确定性随机种子生成三层星点；位置、大小、透明度、冷暖色、漂移方向、持续时间和延迟均不规则。
- 远星最小最慢，亮星较大并带柔光，微尘透明度最低；三层独立漂移形成空间深度。
- 同一世界每次打开保持相同星空；遵循 `prefers-reduced-motion`。

## 状态与交互

- `closed`：封面在中央；点击或 Enter/Space 后左右打开。
- `page(map | archive | characters | graph)`：滚轮、左右拖动、方向键或右侧圆点翻页；前后页旋转、变暗并退入深处。
- `map.preview(entity)`：第一次点击区域，区域高亮，右下浮出简介。
- `map.detail(entity)`：再次点击同一区域或简介，地图退后，完整档案纸页推进到前景；点击正文返回地图预览。
- 书籍和人物使用相同的“点击浮出摘要，再次点击打开正式来源”语义；没有来源时只停留在摘要。
- 页面进入详情后暂时禁止翻页，避免滚轮阅读与页面翻动冲突。

## 响应式

- 目标视口优先保证与参考一致。
- 小于 760px 时内容页宽 90vw，封面宽 78vw；人物最多显示前三张；简介宽度不超过视口 72%。
- 不以响应式为理由改变目标视口的几何关系。

## 已知近似

- 实际封面、地图美术和人物立绘由项目资产决定；缺失时沿用参考中的低对比占位材质。
- 工作台嵌入视口可能小于独立浏览器，但构图比例、状态机和视觉层级保持一致。
