## 明确不做

- 本批不增加新的图片类别；重跑时仍生成当前世界项已有的地图与少量风貌图，并重点修正空间合同、标签、选区与文字展示。
- 不进入历史、故事、角色、图谱、世界包、王国内地图、星图或多宇宙地图。
- 不增加 Checker（检查）Agent，不做文稿编辑、版本比较或用户接受候选图流程。
- 不修改 OpenCode 公共 HTTP、Session V2 数据库、Provider 协议或冻结 Runtime（运行时）。

## 产品不变量

1. 地图图片只是视觉投影；区域 ID、文件 ID、空间几何和来源哈希才是可点击空间事实。
2. 同一自然层级的面状区域不可重叠；河流、山脊等跨域对象使用线状几何；城市、奇观点使用点状几何；人文疆域是独立图层。
3. Harness（智能体运行框架）决定 ID、路径、幂等、层级并集、外轮廓和标签点。模型只提交有语义的空间规划，不得提交相互冲突的最终几何。
4. 旧 V1 地图合同不做猜测迁移。无法从旧数据恢复唯一空间事实时显示“地图数据已过期，需要重新生成”，本轮授权的 Live 项目直接重建覆盖。
5. 玩家展示层不得出现 Agent（智能体）、注册、阶段主编、执行主编、事实依据、因果推演、来源哈希、工具状态等生产过程字段。
6. 内部权威原文和运行账本继续服务后续推演；图志与纪行是独立发布投影，不得覆盖事实底座或创造新规则。

## 实施批次

### 批次 A：权威 Atlas V2

- 将可选对象显式区分为 `area / line / point`，并记录自然、人文图层与可选父子层级。
- 面状同级兄弟使用唯一归属；父区域由子区域并集计算。
- 从区域格集合计算外轮廓，移除相邻格共享边，标签点必须落在实际几何内。
- 为旧合同、交叠、断裂、缺失文件绑定、非法父子关系与来源漂移提供失败关闭。
- 测试：零同级重叠、预期覆盖、父子并集、无环层级、连通性、标签点、无内部边。

### 批次 B：地图三态交互

```text
全图
  → 首次点击 A：只高亮 A
  → 再次点击 A：按 A 的包围盒放大并在右侧打开真实档案
  → 再次点击 A：关闭详情、清除高亮并恢复全图
```

- 在任意非空状态点击 B，切换为仅高亮 B，并关闭原详情。
- 点击对象的完整区域路径，而不是互相冲突的单个泰森格。
- 去掉地图内部白色摘要卡；右侧详情保留地图主视图。
- 测试状态机、缩放恢复、标签/树/区域同步、真实文件加载和过期数据状态。

### 批次 C：图志与纪行发布层

- 每个正式世界对象生成一篇图志；每个奇观必须另有一篇纪行，其他对象不强制纪行。
- 图志采用清楚、克制的现代编辑口吻，说明对象、位置、自然原因与人文后果；禁止字段清单、宏大开场、强行比喻、金句和拔高结尾。
- 纪行使用有身份、路线、季节、目的和知识边界的个人视角，以匿名署名为主；允许偏见和遗漏，但不能篡改权威事实。
- 发布文件绑定源实体 ID 与来源哈希，缺源、越权新增事实或内部工作字段泄露时失败关闭。
- 地图第二次点击默认打开图志；存在纪行时提供独立入口。

### 批次 D：真实重跑与交付

- 使用真实 Provider，从全新 `/growth` 会话重跑经典中世纪题材完整世界项。
- 完成世界内部事实档案、权威地图注册、图志与必要纪行，并覆盖当前 Live 项目。
- 正式 Electron（桌面壳）验证自然与人文视图都没有内部工作痕迹，验证地图三态、区域与文件一致。
- 覆盖桌面正式预览，更新状态证据，执行定向测试、包级类型检查、生产构建与相关 Playwright；不把定向验证称为单体仓库全量测试。

## 停止条件

- Provider 缺失、模型不可调用或正式运行改用 Fixture（测试夹具）/本地模板。
- Atlas 无法得到唯一面状归属，或图片、区域、标签和文件仍没有共同的空间事实。
- 图志/纪行需要覆盖内部权威原文才能实现。
- 改动要求进入公共协议、数据库迁移、冻结 Runtime 或本批明确不做的产品阶段。
- 正式桌面仍显示内部 Agent 工作字段，或地图只能依靠 SVG 假底图才能展示。

## 验收标准

1. 地图选择是可重放的三态状态机，同一区域按三次完成高亮、放大详情、恢复。
2. 多格区域高亮只有外边界，不显示内部泰森裂缝；标签属于对应区域。
3. 自然与人文图层独立且点击均打开对应真实玩家文稿。
4. 玩家视图全文搜索不出现被禁止的内部工作术语；内部账本仍存在且可供 Harness 验证。
5. 真实 Provider 完成一个经典中世纪世界的整个世界项，正式 Electron 读取同一磁盘产物。
6. 代码、测试、状态文档、提交哈希和桌面预览一致。
