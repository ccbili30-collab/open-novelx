## 当前目标

仅在 `D:\CodexW\NovelX_Desktop\work\opencode-novelx` 的 `novelx-ui` 分支，为已经完成的世界 Growth 增加地图和风貌两类真实图片闭环。文本规划与视觉注册使用真实 `openai-compatible/gpt-5.6-luna`；图片任务使用独立的真实图片 Provider（模型服务）端点。缺少模型、来源、图片结果或校验时失败关闭。

## 明确边界

- 本批只做世界地图和少量风貌图。
- 不进入个体图、封面、历史、故事、角色、图谱扩展或世界包导出。
- 不修改 OpenCode 公共 HTTP、Session V2 数据库 Schema、Provider 协议或冻结的 A2.2 Runtime（运行时）。
- 图片是世界事实的视觉投影，不是 Canon（正典）来源；不得从生成图片反推或改写世界事实。
- HTML/SVG 原型和 Fixture（测试夹具）只可验证交互，不能冒充 Live（真实运行）地图。

## 权威链路

```text
全部世界阶段与档案封存
  → Growth 派发干净的视觉主编
  → 视觉主编读取权威实体索引与必要原文
  → Harness（智能体运行框架）生成稳定泰森网格、坐标和版本
  → 视觉主编注册自然/人文空间归属、标签、提示词和稀疏风貌候选
  → Harness 校验实体 ID、来源哈希、覆盖范围、任务预算与路径
  → 写入独立视觉账本和语义蒙版
  → 独立图片 Worker（工作执行器）异步领取任务
  → 图片 Provider 生成真实无字地图或风貌图
  → 校验媒体类型、尺寸、哈希和归属
  → 原子写入资产并把任务标为候选图
  → 正式桌面 UI 投影底图、标签、选择、浮层和候选风貌
```

Growth 根会话只等待视觉注册成功，不同步等待图片生成。图片队列状态为 `queued → generating → validating → attached`，失败状态区分配置缺失、Provider 错误、超时、媒体无效和来源漂移，并允许同一任务幂等恢复。

## 数据合同

### Atlas Scene 与泰森网格

- 本批建立一个世界级 Atlas Scene（图册场景），预留但不伪造子场景。
- Harness 根据冻结种子生成稳定 Voronoi/Thiessen 多边形；每格保存 ID、中心、顶点、邻格、主地表标签和来源实体归属。
- 地理区域与国家/组织都由格集合表达；二者是多对多覆盖，不要求一个国家只绑定一个地理区。
- 山脉和河流可保存有序格链及线轴；普通区域保存格集合。
- 调试语义蒙版可见但默认隐藏；正式底图无文字、无网格、无行政边界。

### 图片任务

- 四类总标签仍是 `map / scenery / individual / cover`，本批只接受前两类。
- 地图任务记录场景、网格版本、语义蒙版哈希、来源哈希、视觉语言版本、Prompt 和目标路径。
- 风貌任务记录 owning entity、子类型、来源文件/哈希、相关格、选择理由、Prompt 和目标路径。
- 风貌稀疏选择：普通建筑与普通地形不生成；真正有世界影响力的自然对象才标记“奇观”；重要政体/组织必须有首都或总部图，没有首都则退为旗帜/徽记。
- Growth 图片先成为候选，不自动替换用户主图。

## 正式 UI

- 地图模式：`底图 / 地理 / 国家 / 语义`；语义模式仅创作者调试使用。
- 底图显示真实 raster（位图）资产；地理和国家标签由结构化图层绘制，不烧进图片。
- 点击任意地块按当前模式解析整个地理区或国家，整组格柔和高亮并隐藏内部裂缝。
- 河流只在点击河流标签或对象时选中整条有序格链。
- 锚点浮层随地图平移缩放，展示已提交档案摘要、图片状态和“打开完整档案”；不在点击时调用模型。
- 实体档案把已生成风貌图放在正文上方；地图浮层可显示同一资产缩略图，文件只保存一份。
- 宽屏正常铺满主工作面，窄窗沿用既有覆盖式 Inspector（检查器）规则。
