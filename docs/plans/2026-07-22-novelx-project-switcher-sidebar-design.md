# NovelX 项目切换栏与当前项目侧栏设计

## 当前目标

- 修复左侧项目窄栏 `+` 点击无响应的问题。
- 让项目窄栏成为全局项目切换入口：每个项目只显示项目名称首字，不使用项目色块或彩色图标。
- 让展开侧栏只显示当前项目与该项目的会话，消除“项目列表里再次嵌套项目列表”的重复层级。
- 选择一个目录后，将其作为独立项目打开；项目文档、会话与 NovelX 工作区状态继续按目录隔离。

## 明确不做

- 不修改 Growth（生长）编排、世界内容或图片生成链路。
- 不改变 Provider（模型服务）、主题和其他全局设置的存储边界。
- 不新增项目模板、目录迁移或数据协议。
- 不在本批次实现项目封面作为窄栏图标；当前只使用名称首字。

## 交互权威

1. 新布局常驻注册唯一的 `project.open` 命令。
2. 项目窄栏 `+`、命令面板与 `Ctrl+O` 统一触发该命令。
3. 命令调用平台目录选择器；取消时零副作用。
4. 选中一个或多个目录时全部登记到当前 Server（服务端）的项目集合，并切换到第一个目录的新会话草稿。
5. 窄栏项目方块点击时复用现有项目切换逻辑：优先已打开标签，其次最近会话，最后创建新草稿。

## 布局与视觉

- 窄栏始终位于最左侧；展开时在其右侧追加当前项目侧栏，不替换窄栏。
- 项目方块保持 42×42 像素，只显示首个可见字符；拉丁字母转为大写，中文保留首字。
- 默认透明、无彩色底；当前、悬停与键盘焦点只使用统一的暖灰边框/浅灰状态。
- `+` 与项目方块使用相同尺寸、圆角和边框语言，不使用虚线框。
- 展开侧栏顶部只出现一次当前项目名称，并提供“置顶项目”和“新建会话”符号按钮。
- 下方可保留跨项目置顶快捷方式；普通会话树只属于当前项目，拖动排序不能跨项目。

## 验收标准

- 新布局运行时，命令表中存在 `project.open`；点击 `+` 会真实调用桌面目录选择器。
- 取消目录选择不会新增项目或会话。
- 选择多个目录时全部登记，但只打开第一个目录的新草稿。
- 项目方块不再渲染 `ProjectIcon`，只显示名称首字。
- 展开侧栏不再循环显示全部项目，只显示当前项目的会话。
- 定向测试、类型检查和生产构建通过，并在真实 Electron（桌面壳）窗口完成视觉与交互验收。
