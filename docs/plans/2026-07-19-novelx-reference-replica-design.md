# NovelX 参考界面复刻设计

日期：2026-07-19

状态：本批次实现与验收完成
视觉基准：`codex-clipboard-74e4bf20-78fc-4989-9642-6183670f1441.jpg`

## 当前目标

把 NovelX Desktop 的会话工作区重建为参考图所示的桌面界面。参考图是 Visual Contract（视觉合同），不是配色灵感。允许替换现有组件，必须保留真实的项目、会话、Agent、文件与设置行为；没有真实运行链的入口必须禁用或隐藏，不得制造假 Live（真实运行）。

当前批次只处理桌面工作区外壳、信息层级、组件视觉语言与必要交互，不改变 Provider（模型服务）、Agent 协议、领域数据模型、权限、Canon 语义或 Runtime（运行时）架构。中央猫插画按用户授权留空。

## 已否决路线

1. 只覆盖 CSS：旧组件的卡片层级、尺寸和结构与参考图不同，已经证明不能达到视觉一致。
2. 静态截图式页面：虽然容易接近参考图，但会丢失真实会话、文件和窗口行为，属于假实现。
3. 继续扩展上一版暖色工作室：上一版的大色块、红色按钮、圆角卡片与参考图的克制桌面工具语言冲突。

采用 Level 2 Reconstruction（二级组件重建）：重建窗口标题栏、应用工具栏、左项目树、中会话面、右资源面板和底部状态栏；复用底层真实状态、命令和数据源。

## 视觉语言

- 背景：近白暖灰，不使用大面积黄色或棕色。
- 参考采样：左栏约 `rgb(249, 240, 231)`，中区约 `rgb(252, 248, 246)`，右栏约 `rgb(248, 242, 232)`。
- 分隔线：1px、低对比暖灰；区域主要依靠线和留白分层。
- 圆角：普通控件 3–6px；输入区不超过 10px。
- 阴影：仅浮层和激活分段允许极浅阴影；主面板不做卡片悬浮。
- 字体：系统无衬线中文字体栈；正文 13–14px，标题 14–16px；不使用装饰性衬线大标题。
- 图标：统一单色线性符号，16px 为主；不用彩色 Agent 按钮，不用 Emoji 代替界面符号。
- 强调色：仅状态点、危险状态或确有需要的选中提示使用；不设大红色主按钮。

## 组件结构与真实行为

### 第一行：窗口标题栏

- 显示小型 NovelX 标志与 `novelx`。
- 保留拖动、双击最大化、窗口系统按钮及键盘行为。
- 移除开发渠道蓝条和可见代码编辑器标签条，但不破坏底层会话导航命令。

### 第二行：应用工具栏

- 左侧：`novelx` 与真实项目名。
- 右侧：玩家模式、Agent 模式、IDE 模式、导入、设置。
- Agent 模式是当前真实创作会话入口，点击聚焦输入区。
- IDE 模式打开真实文件资源面板。
- 导入调用真实项目打开/导入命令；设置打开真实设置对话框。
- 玩家模式在真实 Player Runtime 未接入当前壳层前保持禁用并给出说明，不得伪造切换成功。

### 左栏：项目与会话

- 只展示真实项目与真实会话，不保留上一版“Agent 彩色列表”。
- `+` 创建真实新会话；项目文件夹按钮调用真实项目选择。
- 当前会话使用低对比暖灰底和文字/图标变化表示，不使用彩色胶囊。
- Agent 仍由现有 Agent 选择器和会话状态管理，不在左栏复制一份伪状态。

### 中区：会话与输入

- 顶部保留当前真实会话标题与必要操作，压缩为参考图的单行高度。
- 空状态保持大面积留白；中央猫图不生成、不占位。
- 底部输入区横向铺满中区，保留真实输入、发送、取消和权限行为。
- 新会话默认隐藏参考图中不存在的上游模型、附件和分支按钮；模型与项目仍由真实上下文决定，已有会话的取消和权限处理不变。
- 参考图中的“协助 / 自由”只作为视觉结构参考；若现有运行时没有对应的可验证模式，不把它们伪装成可切换策略。使用真实 Agent/模式文本，或将未接入项明确禁用。

### 右栏：文件、世界与产物

- “文件内容”连接现有真实 FileTree（文件树），文件名、大小与状态不得使用参考图虚构数据。
- “活动与产物”连接现有世界目录与变更/产物状态；世界目录缺失时继续显示真实缺失状态。
- 区块可折叠，折叠状态在当前桌面会话内保持。
- `交流` 聚焦会话输入，`查看全部` 展开真实世界/产物内容。

### 底部状态栏

- 左侧显示真实项目就绪/错误状态。
- 右侧显示当前真实 Agent 和会话状态。
- 不显示 Provider 已连接、世界已生成等未经验证的成功文本。
